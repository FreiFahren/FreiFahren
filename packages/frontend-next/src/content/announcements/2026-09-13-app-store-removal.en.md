---
title: FreiFahren has been removed from the App Store
description: The web app is now the preferred way to use FreiFahren. Installed apps keep working.
date: 2026-09-13
---

Apple has removed FreiFahren from the App Store. The web app at
[app.freifahren.org](https://app.freifahren.org/) is now the preferred way to use FreiFahren. It is
the same app and runs on any phone.

If you already have the app installed, it will keep working for the foreseeable future, and you do
not need to do anything now. If you delete it, though, you will not be able to install it again.

You can add the web app to your home screen. It then looks and works like the installed app did.
